# Lucid Tarkov DMA
## External Hardware DMA Player & Loot Radar for Escape from Tarkov

https://lucid-script.pro/dma

Download the latest launcher from the [Releases](https://github.com/Shurtug/LucidTarkovDMA/releases/latest) page. Join the [Discord](https://discord.gg/QPtxvk6MxU) for updates and support.

Runs entirely on a second PC connected via a PCIe DMA card — no process or hook ever touches the game machine. Zero footprint on the target system.

## Features

### Hardware Aimbot
- Routed through a MAKCU USB hardware mouse box — real mouse movement, not an injected input call

### Visuals
- **ESP** — players, loot and quest objectives, box and skeleton overlays
- **Chams** — custom player/gear chams
- **Radar** — full-map radar with live loot prices
- **Dashboard** — phone/LAN web dashboard for remote control

### Memory-write cheats
- No-Recoil, Thermal & Night Vision, Full Bright
- Infinite Stamina, Big Head, Extended Reach
- Loot-through-walls
